# Edi native media runtime

FFmpeg and FFprobe are independent command-line programs used by EdiAula. This bundle is built from the exact source archives listed in `build-information/sources.lock.json`. It is distributed under GPLv3, with dependency licenses in `licenses/` and FFmpeg's license in `LICENSE.FFmpeg.txt`.

`Corresponding-Source.tar.xz` contains every original library source archive, the Dockerfile, cross-compilation configuration, complete build recipe, source checksums and toolchain version inventory used for this bundle. The recipe applies one context-checked correction to FFmpeg 9.0.2's `libavfilter/af_arnndn.c`: zero the three GRU input buffers before filling them. Its dot products round input lengths up to four floats; the original stack padding was uninitialized, and zero weights multiplied by a NaN still contaminated the recurrent network. The patch is embedded in `build.sh`, rejects changed source context and is included in this corresponding-source archive and recipe digest. No codec or quality assertion is disabled. The archive is installed beside these programs and may be copied and redistributed under their respective licenses.

The hardware H.264 encoders are NVIDIA NVENC (from `nv-codec-headers`), AMD AMF (from the AMF headers published by GPUOpen) and Windows Media Foundation, which reaches Intel Quick Sync and other hardware encoders. Only their headers are compiled in: the runtimes ship with the graphics driver or with Windows, are loaded when present and are not redistributed here. The MIT notice carried by the AMF headers is copied to `licenses/amf/LICENSE.txt`.

To rebuild, extract the source archive, copy `recipe/*` and `sources/` into a new build directory, and run `docker build --output type=local,dest=output .` in that directory; `--build-arg BUILD_JOBS=<n>` sets the compiler parallelism (default 2) without changing the result. Docker needs network access to the pinned Ubuntu image and Ubuntu package repositories for the compiler. The input hashes are verified before compilation. The FFmpeg configuration and toolchain versions are recorded in `build-information/`.

The Edi application communicates with these programs through their documented command-line interfaces. Licensing terms for this native bundle do not replace the separate terms for Edi.
